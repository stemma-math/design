Native selects keep their chevron in place during focus, invalid states and blur. Field surfaces transition only their background colour, preserving the native picker and stable field dimensions.

Nested navigation items use a smaller height and font, with a quiet tree guide under the heading's chevron. Navigation headings can group several trailing actions in `.nav-section__actions`; their actual width reserves space for the heading while destinations still span the section. The new `arrow-right` glyph complements `arrow-left` and distinguishes opening the full list from folding a section.

`.menu__row` places a destination beside an independent `.menu__action`. The menu element includes both in its keyboard navigation and selection events, and skips disabled targets. `.account` provides an avatar, a name and a secondary line inside one person link, with a separate trailing icon action. Both components follow the local card or brand-surface tokens.
