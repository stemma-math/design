An account row can open its menu as one `.account.account--menu` button, with a truncated name, optional secondary line and a chevron that follows the expanded state. `<stemma-menu match-width>` matches the menu to its trigger, follows size changes while open and keeps the menu within the viewport. The boolean `matchWidth` property reflects the attribute.

`.menu__header` presents a person's avatar, name and secondary line before the menu items. Both text lines truncate, and the header stays outside the arrow-key selection. Clicking it preserves keyboard navigation and Escape without choosing an item. It works in either page appearance and on the brand surface.

The new `person` glyph marks a single person's profile, matching `add-person` and `group`.
