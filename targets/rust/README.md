# stemma-design

Stemma's design system for Rust: the files of the web target
(`@stemma-math/design`) as constants, to serve from a program or to inline
in a page kept in a single HTML file. No dependencies.

```toml
[dependencies]
stemma-design = { git = "https://github.com/stemma-math/design", tag = "vX.Y.Z", features = ["elements"] }
```

## What it provides

| Item                          | What it is                                                                                                                                                                                |
| ----------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `get(path)`                   | The `Asset` at a path such as `web/tokens.css`: its bytes and its media type.                                                                                                             |
| `serve(prefix, request_path)` | The asset a request asks for when the files are served under `prefix`, as `/design`.                                                                                                      |
| `assets()`                    | Every asset this build carries.                                                                                                                                                           |
| `bundle::Bundle`              | An inline bundle for a page's `head`: the stylesheets, the faces as base64 WOFF2 (the whole math face with `math(true)`), the glyph sprite and, with `elements`, the elements' behaviour. |
| `web/…`                       | The web target's stylesheets, faces, glyph sprite and grain, always.                                                                                                                      |
| `elements/…`                  | The custom elements of `@stemma-math/design-elements`, with the `elements` feature.                                                                                                       |
| `brand-kit/…`                 | Favicons, application icons and the marks as SVG, with the `brand-kit` feature.                                                                                                           |

The files refer to each other by relative paths, so serving `web/` and
`elements/` side by side under any prefix is all a page needs:

```rust
// In a request handler:
if let Some(asset) = stemma_design::serve("/design", path) {
    // respond with asset.bytes, Content-Type: asset.content_type
}
```

A page that is also saved as one file, rendered with minijinja for
example, puts a bundle in its `head`:

```rust
use stemma_design::bundle::{Bundle, Element, Faces, Subset};

let head = Bundle::default()
    .faces(&[Faces::Ui, Faces::Prose, Faces::Mono])
    .math(true)
    .subsets(&[Subset::Latin, Subset::LatinExt])
    .weights(&[400, 600, 700])
    .elements(&[Element::ThemeSwitch, Element::CopyButton])
    .render();
// context! { design_head => head }, then {{ design_head | safe }} in the template.
```

The bundle is built from the crate's files rather than picked from bundles
prepared in advance: every combination of faces, ranges, weights and
elements would not fit in a crate. It is the same, byte for byte, as
`tools/bundle.py` writes for the same options; the tests check it.

## Generated files

`assets/`, `src/assets.rs`, `src/bundle_data.rs` and `tests/bundles.tsv` are
generated by the repository's `tools/targets.py` from the other targets,
and must not be edited here.
