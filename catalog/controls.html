Components

Controls

What a person acts with: buttons, and every way to enter or choose a value. Each is a native control with a class; an element adds behaviour where HTML has none.

Button

Outlined and neutral by default, the secondary action. The primary button is the one action a view is for, in the accent unless an intent says otherwise.

.button--primary--quiet--link--icon--inline--small--success--warning--danger

thm:fermat-little An inline button, as large as the text around it.

Field

A label, the control, and a hint or an error under it. An error says what happened and how to fix it.

.field.field__label.field__hint.field__error.input.input--mono
As it appears in the index.
An identifier needs a name after its colon.

Select

One option among many. <stemma-select> draws its own list over a native select, which stays, hidden, for forms and events. Without script, the native one is shown, styled.

<stemma-select>select.inputplaceholder

Choose an option.

Checkbox, radio and switch

A choice and its words on one line, so the words are the target. A switch is a checkbox with role="switch", for a setting that takes effect at once.

.choice.fieldsetrole="switch"

Range

A value along a scale, where where it sits matters more than the exact number. <stemma-range> fills the track up to the value in every engine and shows it.

input[type="range"].range<stemma-range>

Stepper

A number taken down and up by its step. Holding a button repeats it; the input can still be typed into.

.stepper--small<stemma-stepper>

Segmented control

Two or three views of one thing. <stemma-segmented> makes it one choice, with the arrow keys.

.segmented<stemma-segmented>

Full-width segmented control

Equal-width options fill a narrow column. Use the class on a segmented group, or the boolean fill attribute on the theme switch; it also reflects the element's fill property.

.segmented--fill<stemma-theme-switch fill>

Filter chips

Chips turned on and off to filter a view. single allows one at a time.

button.chip<stemma-filter-chips>
