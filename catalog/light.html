Grain strength

The CSS light has a gentle texture by default. Set --grain from zero to one to adjust its opacity without changing the gradient. This controls the CSS fallback; the live WebGL light keeps its preset's own grain.

.brand-light--grain

Default texture

Controls on a brand surface

The brand context uses on-dark ink and dark control tokens in either page appearance. Put it on a navy panel, or on the dark region of a brand light; controls over the pale end need the page's own tokens. It does not select the page appearance. A menu or popover should stay inside this context in the DOM.

.brand-surface.brand-light.button .chip.avatar.nav-item .menu<stemma-theme-switch fill>
